# Student Management System

A Python-based Student Management System built using Object-Oriented Programming (OOP) and JSON for data storage.

## Features

- Add new student records
- View all students
- Search students by roll number
- Update student information
- Delete student records
- Calculate total and average marks
- Assign grades automatically
- Student login system
- Input validation
- Persistent JSON data storage

## Technologies Used

- Python
- Object-Oriented Programming (OOP)
- JSON
- File Handling

## How to Run

1. Clone this repository:

```bash
git clone https://github.com/aka-shekhar/student-management-system.git
```

2. Open the project directory:

```bash
cd student-management-system
```

3. Run the application:

```bash
python main.py
```

## Data Storage

Student records are stored locally in `students.json`.
